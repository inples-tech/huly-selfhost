# Брендинг

Фронт забирает `branding.json` по адресу из `BRANDING_URL` и ищет в нём ключ,
равный хосту, с которого открыт интерфейс (`window.location.host`). Не совпал —
брендинг молча не применяется, поэтому ключ здесь `erp.inples.ru`, а не `*`.

Из файла фронт читает `title`, `links`, `languages`, `defaultLanguage`,
`lastNameFirst` и `defaultApplication`. Поля для логотипа внутри интерфейса
в этой версии нет: значок в левом верхнем углу зашит в сборку фронта, меняются
только заголовок вкладки и favicon.

Иконки собраны из `logo.svg` (`cairosvg`, размеры 32/180/192/512). Сам svg —
растр в обёртке со скруглением, поэтому пересобирать иконки нужно из него же,
а не масштабировать png.

Каталог монтируется во фронт как `/app/dist/branding`, файл — ещё и в account
и workspace как `/var/cfg/branding.json`: оттуда берётся название продукта для
писем с приглашениями и кодами входа.
